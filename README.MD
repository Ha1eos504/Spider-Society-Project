# Spider-Society Savior - Setup Guide 🕷️

Here's a quick guide to getting your project up and running in Visual Studio Code (VS Code).

## 🎯 Your Mission
Doc Ock has hacked the network. Your job is to:
1. **Clean up the Landing Page (`index.html`):** Fix the broken HTML, remove the neon green background, and hide the Doc Ock image using CSS.
2. **Add the Memo:** Insert the official Spider-Society welcome text onto the restored page.
3. **Build the Gadget Lab (`gadget-lab.html` & `script.js`):** Finish the second page by programming a button to randomly generate web-shooter upgrades from a JavaScript array.
4. **Be Creative!** Have some fun with this project and go beyond the features asked of...the more the merrier!!

## 🛠️ VS Code Setup
1. Download and install [VS Code](https://code.visualstudio.com/) if you haven't already. 
2. Open VS Code, go to **File > Open Folder**, and select your project folder. 📂
3. Open the Extensions view by clicking the blocks icon on the left sidebar (or press `Ctrl+Shift+X` / `Cmd+Shift+X`). 🧩
4. Search for **Live Server** (by Ritwick Dey) and click **Install**. ⚡

## 🚀 Running the Project
1. Open the `index.html` file in VS Code. 📄
2. Right-click anywhere inside the code and select **Open with Live Server** (or click the "Go Live" button at the bottom right of your screen). 🌐
3. Your default web browser will automatically open the site. 
4. Every time you save your HTML, CSS, or JS files, the browser will automatically refresh to show your changes! 💥

Good luck fixing the network! 🦸‍♂️
